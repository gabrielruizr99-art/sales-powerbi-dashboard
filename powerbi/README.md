# Power BI

El informe se almacena como proyecto Power BI para facilitar el control de versiones:

- `sales-powerbi.pbip`: punto de entrada del proyecto.
- `sales-powerbi.Report`: definición PBIR de páginas y visuales.
- `sales-powerbi.SemanticModel`: modelo semántico en TMDL.

Abre `sales-powerbi.pbip` con una versión de Power BI Desktop compatible con proyectos PBIP. Las credenciales de PostgreSQL se configuran únicamente en el entorno local y no deben incorporarse al repositorio.
