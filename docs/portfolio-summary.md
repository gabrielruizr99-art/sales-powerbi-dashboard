# Resumen para portafolio

## Descripción breve

Sales Power BI Dashboard — Ferretería es una solución integral de inteligencia de negocios construida sobre 10 000 ventas ficticias de una ferretería peruana. El proyecto implementa limpieza y validación con Python y Pandas, un modelo estrella en PostgreSQL, dieciocho medidas DAX y un informe Power BI profesional de tres páginas en formato PBIP/PBIR.

## Aporte del proyecto

La solución permite analizar ventas netas, utilidad, margen, ticket promedio, volumen, descuentos y costos; comparar resultados con el año anterior; seguir acumulados YTD; e identificar productos, categorías y sucursales de mayor desempeño. El flujo completo es reproducible y está preparado para control de versiones.

## Puntos destacados

- Pipeline CSV → Python/Pandas → PostgreSQL → modelo estrella → Power BI.
- 10 000 operaciones ficticias entre enero de 2024 y agosto de 2026.
- Seis dimensiones, una tabla de hechos y seis relaciones activas.
- Dieciocho medidas DAX, incluidas métricas de inteligencia de tiempo.
- Tres páginas: Resumen Ejecutivo, Análisis de Ventas y Productos y Sucursales.
- Diseño ejecutivo con navegación, filtros, rankings, tendencias y matriz jerárquica.
- Tecnologías: Power BI, PBIP/PBIR, PostgreSQL, Python, Pandas, SQL y Git.

## Texto corto reutilizable

Desarrollé un dashboard comercial de Power BI para una ferretería peruana simulada, partiendo de 10 000 registros ficticios. Construí el proceso de limpieza con Python y Pandas, el modelo dimensional en PostgreSQL y un informe PBIP/PBIR de tres páginas con indicadores de ventas, rentabilidad, comparaciones interanuales, acumulados YTD y análisis de productos y sucursales.
